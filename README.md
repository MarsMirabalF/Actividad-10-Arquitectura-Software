Tienda de videojuegos Epic Games

Proyecto en Java que simula por consola una tienda de videojuegos. El usuario ve el catalogo, compra juegos, recibe avisos y al salir ve su biblioteca de juegos comprados.

Requisitos
Java JDK 22 o superior
Todo se ejcuta por terminal

Como ejecutar:
Abre una terminal dentro de la carpeta raiz del proyecto la que contiene Main.java

Compila:
javac Main.java

Ejecuta:
java Main

Puedes probar tambien:
Java Main.java
